# Dent Art | Atrévete a Sonreír

VIP smile studio platform for Dent Art in Poza Rica, Veracruz—lime green brand identity, concierge booking, and 24/7 emergency care.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npx tsc --noEmit
npm run build
```
